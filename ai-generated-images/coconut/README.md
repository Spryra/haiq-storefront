# 🥥 Coconut — Image Generation Guide

## Product Characteristics

The **Coconut** cookie is:
- **Base:** Light to medium brown chocolate base (not dark like Venom)
- **Surface:** Subtly cracked/textured with visible coconut flakes
- **Coating:** White powdered sugar mixed with shredded coconut — creates a "snowball" appearance
- **Crumb:** Lighter, more cake-like texture (compared to fudgy dark chocolates)
- **Aroma appeal:** Should look fresh, tropical, inviting
- **Colour palette:** Warm browns, bright whites, golden coconut tones
