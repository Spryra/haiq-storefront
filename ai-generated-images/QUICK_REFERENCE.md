## Naming Convention

Save each generated image as:

```

```

**Examples:**
- `venom-hero-variation-1.png`
- `venom-overhead-variation-2.png`

- etc.

**Generate 2–4 variations per scene** for best selection.

## Quality Checklist ✅

Before saving:
- [ ] No text/watermark
- [ ] Cookie matches reference (shape, pattern, coating)
- [ ] Black background is pure black
- [ ] Powder is crisp white
- [ ] Single directional light (no multiple light sources)
- [ ] Sharp focus on cookie detail
- [ ] Aspect ratio correct (1:1 or 4:3 or 16:9)
